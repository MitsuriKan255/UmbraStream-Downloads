# Versiones públicas de NovaStream

## 0.3.9

- Primera publicación de NovaStream en el repositorio de descargas.
- El actualizador de macOS y Windows consulta **NovaStream-Downloads** desde el menú **Buscar actualizaciones**.
- Paquetes para macOS universal y Windows 11 x64, con sus sumas SHA-256.

Desde la 0.3.8 o una versión anterior, instala una vez esta edición para que el actualizador utilice el nuevo repositorio.
